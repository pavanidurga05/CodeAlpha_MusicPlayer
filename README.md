# 🎵 CodeAlpha Music Player

A modern and responsive music player built using HTML, CSS, and JavaScript.

## Features

* ▶️ Play / Pause
* ⏭️ Next / Previous Song
* 🔍 Real-Time Search
* ❤️ Favorite Songs
* 🔀 Shuffle Mode
* 🔁 Repeat Mode
* 📊 Progress Bar
* 🔊 Volume Control
* 📱 Responsive Design
* 🎨 Modern UI

## Technologies Used

* HTML5
* CSS3
* JavaScript
