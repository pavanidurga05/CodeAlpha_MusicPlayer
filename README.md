
# 🎵 CodeAlpha_MusicPlayer

A modern premium music player web application built from scratch using **HTML5, CSS3, and Vanilla JavaScript**.

**Musicify** provides a dark mode user interface inspired by premium streaming platforms. It features a custom splash screen, seamless tab-based navigation, an interactive side navigation drawer, real-time search filtering, a favoriting database system, interactive custom progress/volume sliders, and full audio stream playback capabilities.

---

## ✨ Features

* **Premium Dark Mode UI:** High-fidelity, mobile-first design with fluid card interactions and neon-green accents.
* **Animated Splash Screen:** Preloads branding assets with a smooth timing transition loop.
* **Core Media Control Engine:** Real-time play, pause, next track skip, and previous track skip actions.
* **Mutual Exclusivity Logic:** Intelligently disables Shuffle Mode automatically when Repeat Mode is engaged, and vice versa.
* **Interactive Timelines:** Stutter-free custom progress track bars and slider input controllers.
* **Working Side Navigation Drawer:** Slides open from the top-left corner to access history and secondary configurations.
* **Contextual Track Dropdown Options:** Dedicated menu panel accessible via the top-right ellipsis button for quick metadata analysis.
* **Dynamic Tab Shell Framework:** Smooth view-switching mechanics between Home, Search, Favorites, and Playlist hubs.
* **Live Search Indexing:** Real-time character filtering that matches track lists on the fly.
* **Persistent Favorites Pool:** Inline list handling allowing users to add or remove tracks instantly from their library collections.

---

## 🛠 Technologies Used

* **HTML5:** Semantic document scaffolding and audio stream integration nodes.
* **CSS3:** Custom properties, flexbox grids, range input skin modifications, and keyframe interface animations.
* **JavaScript (ES6+):** Event listener pipelines, background rendering pools, and core media stream lifecycle algorithms.
* **Font Awesome:** Scalable icon vectors.
